# 🐉 端午文化探险 — Dragon Boat Festival Game

> 一款面向Z世代学生的端午文化H5小游戏，三关探险 + 文化传承，单文件无依赖。

![国潮水墨风](https://img.shields.io/badge/风格-国潮水墨-red) ![HTML5](https://img.shields.io/badge/技术-HTML5-orange) ![单文件](https://img.shields.io/badge/部署-单文件-green)

## ✨ 游戏简介

屈原穿越时空来到现代，带来了被遗忘的**端午文化碎片**。玩家需要通过三关挑战，帮他把文化记忆传递给更多人。

**核心叙事：屈原的肉身随江水而去，但他留下的诗篇、节日与精神，两千年来从未离开——这就是文化的力量。**

## 🎮 三关玩法

| 关卡 | 玩法 | 文化内涵 |
|------|------|----------|
| 🥁 **第一关·击鼓传声** | 跟随鼓点节奏点击/空格敲击鼓面 | 龙舟非遗文化 |
| 📜 **第二关·端午问答** | 4选1知识问答（5题） | 楚辞、习俗、节气 |
| 🍃 **第三关·投粽入江** | 点击粽子投入江中，击退鱼群保护屈原 | 粽子起源与地区差异 |

通关后解锁 **端午祝福分享卡** + 屈原寄语。

## 🛠️ 技术特点

- **单文件 HTML**：`duanwu.html` 一个文件包含全部代码
- **零外部依赖**：无 CDN、无框架，支持离线打开 / 微信内嵌
- **Web Audio API**：自生成鼓声、水声等音效，无需音频文件
- **CSS 粽子**：纯 CSS 绘制三角锥形粽子（碱水粽/肉粽/甜粽）
- **国潮视觉**：朱砂红主色 + 水墨纹理 + 金色点缀
- **排行榜**：localStorage 本地存储，可扩展 JSONBin 云端同步

## 📌 设计原则

1. **正能量叙事** — 不渲染投江悲剧，聚焦文化传承精神
2. **寓教于乐** — 文化知识藏在游戏关卡中，不枯燥
3. **轻量易传播** — 单文件即分享，适配手机和电脑
4. **隐私安全** — 本地存储为主，不强制联网
